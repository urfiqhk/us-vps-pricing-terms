## 哪些人不用买 CN2 GIA

面向北美或欧洲访客的外贸站、跑采集和定时任务、做异地备份、给 CDN 做源站，这些场景的访问者不在国内，回国延迟不影响业务。$10–$20 档的国际线路机器更合适，同样的预算可以买两台做冗余，比一台优化线路机器更抗故障。

只有一类人值得为 CN2 GIA 付溢价：主要访问者在中国大陆，且对晚八点到十二点的稳定性有要求。电信用户在这条线上收益最大；联通移动为主的，CMIN2 或 AS9929 方向的套餐价格低一截，体验差距没有价格差距那么大。
